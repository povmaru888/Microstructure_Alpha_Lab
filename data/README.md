# Market data

Raw LOBSTER files are licensed data and must never be committed or redistributed.
Obtain them directly from the provider, accept the terms that apply at download
time, and place the two extracted files under:

`data/raw/lobster/AAPL_2012-06-21_10levels/`

Expected local aliases are `message.csv` and `orderbook.csv`; preserve the actual
archive and internal filenames in `data_manifest.json`. The repository does not
claim that data has been downloaded. See `docs/source_verification.md`.
